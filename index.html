关于本站

这是一个纯前端、无需构建的 GitHub Pages 博客。把 Markdown 文件放到 posts/ 目录后，网站会自动发现并渲染文章。

文章可以使用 YAML Front Matter 设置标题、日期、摘要、标签和封面：

---\ntitle: 我的第一篇文章\ndate: 2026-08-28\ndescription: 这是摘要\ntags: [随笔, 技术]\ncover: assets/images/example.jpg\n---
